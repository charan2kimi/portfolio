Architecture

Seven planes around one data path. At 10B+ transactions a day, every design choice below is an economics choice: reject early and cheap, authenticate once, verify message trust explicitly, compose policy without code, and attribute every millisecond.

One transaction

  1. Ingress, streamed not buffered. The transaction enters over any mediated protocol and is normalized into the 4-stage pipeline without buffering the payload; memory reservation admits it or sheds it with a 503.
  2. Reliability contract attaches. Where the transport demands it, a WS-ReliableMessaging sequence is established with exactly-once delivery and range-based acknowledgments; WS-Addressing tags the message for correlation.
  3. Screening runs cheapest first. Network IP rules, then ANTLR application filters, then WAF signatures; intrusion sensors update per-IP, per-user, and per-API state and can block, throttle, alert, or quarantine on the spot.
  4. Identity resolves once. One of the 11+ brokered methods authenticates the caller; the credential cache answers 90%+ of lookups without a roundtrip; throttling and replay caches guard the door.
  5. Federation happens at the edge. A SAML assertion is issued or consumed, or an OAuth token is minted or validated against the per-policy token caches; backends never do their own identity plumbing.
  6. Message security is enforced. Signatures are verified or applied, certificate chains are path-validated with cached revocation checks, and payloads are decrypted or encrypted per policy.
  7. The policy pipeline executes. Composed processors run in stages, with sandboxed Nashorn or Python scripts covering the last mile; every stage is bounded by a timing checkpoint.
  8. Cache, then balance. The cache answers hits immediately and coalesces concurrent misses into one backend call; on a true miss, one of 9 balancing strategies places it, with health checks and failover behind it.
  9. Egress with attribution and evidence. The response streams back through Process Response and Send to Client; 7 checkpoints attribute the latency, signed logs flow to the SIEM, and alerting fires if a threshold tripped.

Key decisions

Stream, never buffer

Decision: a zero-copy, 4-stage bidirectional streaming pipeline with per-transaction memory reservation and backpressure that answers overload with an explicit 503.

Alternative considered: buffer-and-forward proxying: read the whole message, then operate on it. Simpler to write and debug.

Consequence: at 10B+ transactions daily the arithmetic closes only one way. Zero-copy keeps per-transaction memory near constant, terabyte-scale objects move through the same machinery as small calls, and overload degrades by deliberate load shedding instead of collapse.

Constant-time sensors, not per-request deep analysis

Decision: an intrusion-detection engine built from O(1) sensors evaluating 31 criteria, with graduated actions: block, throttle at 1-99%, alert, quarantine.

Alternative considered: heavyweight per-request inspection or offline anomaly analytics: richer verdicts, paid for on the hot path or delivered after the damage.

Consequence: detection rides the data path at under 5% overhead, verdicts land per-IP, per-user, or per-API in real time, and percentage throttling gives a proportional response where a binary block would take out legitimate traffic with the abuse.

Configuration as a managed object model, code as the escape hatch

Decision: the ManagedObject framework, 200+ policy types, annotation-driven, versioned and auditable, with a 60+ processor no-code builder on top and sandboxed scripting reserved for the last mile.

Alternative considered: a scripting-first gateway where every policy is code. Maximum flexibility, minimum governance.

Consequence: policies became reviewable, versionable, promotable artifacts instead of scripts, onboarding fell from weeks to days, and a decade later the managed-policy shape returned as the governance overlay for AI tools.

Active-passive with MAC virtualization, not active-active

Decision: one active appliance and one passive, with MAC address virtualization so the survivor assumes the pair's network identity, split-brain prevention so one node ever owns it, and 30-40 second recovery.

Alternative considered: active-active clustering: better utilization, but state synchronization and split-brain hazards multiply on a stateful security workload.

Consequence: failover is deterministic at a sub-minute recovery target, neighbors keep forwarding without relearning the network, and 99.99% targets held on workloads where a split brain would mean two gateways making conflicting security decisions.

What the AI platforms inherited

Policy overlay → MCP governance

Sentry's ManagedObject policy pipeline, 200+ types composed without code, versioned and audited, is the direct ancestor of the governance overlay for MCP tools: scoped authorization, rate limits, and audit attached to artifacts instead of hand-written per integration.

Identity brokering → tenant identity

An authentication broker with 11+ methods behind one interface, plus caching that eliminated 90%+ of directory roundtrips, taught the pattern the AI platforms use for Okta, GitHub, and local identity: resolve identity once at the edge, scope everything behind it.

Stage checkpoints → agent tracing

The 7 timing checkpoints that attribute gateway latency stage by stage became span-level trace attribution in the agent runtime: same discipline, new substrate. When an agent run is slow, the trace names the hop that spent the time, exactly as the pipeline did for a transaction.
